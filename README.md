# ✦ Glass To-Do

A fast, modern, and beautifully crafted to-do and productivity web application featuring a sleek glassmorphism aesthetic.

![Glass To-Do Preview](https://img.shields.io/badge/status-active-brightgreen)
![License](https://img.shields.io/badge/license-MIT-blue)

---

## ✨ Features

- **Glassmorphic UI**: Modern aesthetic with dynamic blur, smooth shadows, and responsive dark/light theme switching.
- **Task Management**: Create, edit, complete, delete, and organize tasks effortlessly.
- **Priority & Categorization**: Organize tasks by priority (High, Medium, Low) and custom categories (Work, Personal, Study, etc.).
- **Live Search & Filtering**: Instant search with real-time filters by completion status, priority, or category.
- **Due Dates & Reminders**: Keep track of deadlines with intuitive date selectors.
- **Local Persistence**: Tasks and preferences are automatically saved in `localStorage`.
- **Keyboard Shortcuts**: Built-in accessibility and quick navigation for power users.

---

## 🚀 Quick Start

No installation, build tools, or dependencies required!

1. Clone the repository:
   ```bash
   git clone https://github.com/Ayushman575/To-Do-list-.git
   ```
2. Navigate to the project directory:
   ```bash
   cd To-Do-list-
   ```
3. Open `index.html` in any modern web browser:
   - Double click `index.html`, or
   - Use VS Code Live Server / any local static server.
